# sigao-with-cuv-names

天主教的《思高本》圣经是一个美好的译本，只可惜其中的译名跟《和合本》大相径庭。
本repo只做一件事，就是把思高本中的译名跟和合本统一，其余内容一字不易。
这样便于新教的人士可以了解思高本，也便于天主教内人士了解和合本的译名，一举两得，岂不美哉？

将思高本中的神名、人名、地名换成和合本译名，并将原有 TeX 文件转换为 UTF-8 纯文本。正文的措辞、段落标题、章号、节号和注释沿用思高本。

**本仓库目前不是完整圣经。** 指定源目录虽然有 73 个经卷文件，但其中 **61 个只有书名，没有正文**；另外 12 个有正文，其中《出谷纪》只有第一章。本次转换忠实保留源目录现状，没有补写或拼接其他来源的经文。每个文件的状态见 [卷目.tsv](卷目.tsv)。

## 文件与内容

- 文件名沿用源目录的编号和英文书名，只把 `.tex` 改为 `.txt`，例如 `01_Genesis.txt`、`73_Revelation.txt`。
- 12 个有正文的文件为：`01_Genesis.txt`、`02_Exodus.txt`、`39_Jonah.txt`、`55_Galatians.txt`、`63_Titus.txt`、`64_Philemon.txt`、`67_1_Peter.txt`、`68_2_Peter.txt`、`69_1_John.txt`、`70_2_John.txt`、`71_3_John.txt`、`72_Jude.txt`。
- 其余 61 个 TXT 只含源文件中的书名。多俾亚传、友弟德传、玛加伯上下等思高本独有经卷也属于这一情况。
- 节号记为 `〔1〕`，原有合并节号照留；注释记为 `【注1】`，按各文件连续编号，放在原有位置。
- 保留思高本的中文书名体系，仅同步替换其中的人名、地名。例如《若望福音》改为《约翰福音》，《出谷纪》仍称《出谷纪》。注释里的经卷简称和交叉引用保留原样。

## 译名处理

- `天主` → `上帝`；`上主`、`雅威` → `耶和华`。
- 例如 `厄娃` → `夏娃`、`梅瑟` → `摩西`、`保禄` → `保罗`、`若望` → `约翰`、`伯多禄` → `彼得`、`迦拉达` → `加拉太`。
- 保留思高本的其他用语，例如“圣神”“宗徒”“恩宠”，不把正文重写成和合本。
- 同名异人、同地异名按上下文处理。《创世纪》沿用此前已核对的转换，包括亚伯兰／亚伯拉罕、以诺／哈诺、沙拉／示拉等区别。
- 无和合本对应名称的独有人物和注释中的近现代名称保留。例如多俾亚、友弟德，以及《出谷纪》注释中的辣默色斯二世、特耳玛斯顾大；城市辣默色斯则改为“兰塞”。
- 《腓利门书》注释中的“费氏”“敖氏”展开为“腓利门”“阿尼西谋”，以免换名后简称失去所指。
- 和合本不同排印本有少量地名异写。本次采用的具体写法列在 [译名对照.tsv](译名对照.tsv)，例如大马色、尼哥坡里、加帕多家；原文已经与所参照和合本同名的，如克里特、西班牙、尼罗河，保持原样。

## 核对记录

73 个源文件均有同名 TXT。共保留源文件的 **2,146 处节号标记和 285 条注释**；合并节号只计一处标记，不据此推算经文总节数。

转换程序核对了各文件的节号顺序、注释数量，并独立比较去掉 TeX 排版符号后的全部文字，确认除已记录的译名处理外，没有因转为 TXT 丢失文字。《创世纪》与此前已上传版本逐字一致。源文件本身的缺文、排印和抄录问题不在本次改写范围内。
