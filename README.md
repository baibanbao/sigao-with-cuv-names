# sigao-with-cuv-names

天主教的《思高本》圣经是一个美好的译本，只可惜其中的译名跟《和合本》大相径庭。
本repo只做一件事，就是把思高本中的译名跟和合本统一，其余内容一字不易。
这样便于新教的人士可以了解思高本，也便于天主教内人士了解和合本的译名，一举两得，岂不美哉？

本仓库现已收齐思高本 **73 卷经文正文**，按原来的编号和英文书名保存为 UTF-8 简体 TXT。以思高本为正文，只统一译名，不用和合本经文替换思高本措辞。

## 文件与内容

- 文件名沿用 [IoannesRui/bible 的 books 目录](https://github.com/IoannesRui/bible/tree/6cfbf71622ead0aaef5a1f6c03d62b01a42a169c/books)，例如 `01_Genesis.txt`、`73_Revelation.txt`。
- 原目录中 61 卷只有书名，《出谷纪》只有第一章；这些缺文已从其他思高本来源补齐。《创世纪》等原来完整的 11 卷保持原文件内容，《出谷纪》第一章及其注释也保留。
- 包含多俾亚传、友弟德传、玛加伯上下、智慧篇、德训篇、巴路克等独有经卷，以及《艾斯德尔传》六段补录、《达尼尔先知书》的增补部分和《德训篇》希腊译本序言。
- 节号记为 `〔1〕`；原有合并节号、分段节号和经文次序照留。注释记为 `【注1】`，按每卷连续编号。
- 中文书名沿用思高本体系，只同步转换书名中的专名。例如《若望福音》改为《约翰福音》，《出谷纪》仍称《出谷纪》。注释中的经卷简称和交叉引用保留原样。
- 本次补齐的是经文正文。现有来源提供的注释一并保留，**不等于思高本全套注释已收齐**。

各卷章数、节号标记数、注释数和文件校验值见 [卷目.tsv](卷目.tsv)；各章的具体来源及补充说明见 [来源索引.tsv](来源索引.tsv)。

## 译名处理

- `天主` → `上帝`；`上主`、`雅威` → `耶和华`。
- 人名、地名及相关专名采用和合本译名，例如 `厄娃` → `夏娃`、`梅瑟` → `摩西`、`保禄` → `保罗`、`若望` → `约翰`、`伯多禄` → `彼得`。
- 保留思高本的其他用语，例如“圣神”“宗徒”“恩宠”。正文只作繁简转换、纯文本排版和所记录的译名处理。
- 无和合本对应译名的独有人物、地点，以及注释中的近现代名称，保留思高写法。例如多俾亚、友弟德、敖罗斐乃。
- 同一思高译名对应多个和合本译名时，结合经文判断。例如斐理伯可对应腓力、腓利或腓立比；西默盎可对应西缅或西面。人名和普通词、量词也分开处理。
- 《创世纪》沿用此前核对的版本，包括亚伯兰／亚伯拉罕、以诺／哈诺、沙拉／示拉等区别。《腓利门书》注释中原来依赖旧译名的“费氏”“敖氏”，沿用已展开的“腓利门”“阿尼西谋”。
- 和合本不同排印本有少量异写。本仓库采用的具体写法及出现次数列在 [译名对照.tsv](译名对照.tsv)，如大马色、推罗、埃提阿伯等。

## 核对记录

全部 73 个 TXT 均含正文，共 **1,328 章、35,742 处节号标记、293 条注释**。合并节号只计一处标记，分段节号可能重复，因此“节号标记数”不等于按某一种圣经版本计算的总节数。

转换时逐段检查了新增正文，核对章序、节号次序、补录和注释，确认纯文本输出没有丢掉已取得的经文段落，文字变动均限于记录的译名。原有 11 卷完整文件逐字未变，《出谷纪》第一章仍保留原文。

思高本和和合本的章、节划分及底本取舍并不完全相同。例如《约伯传》部分经文有调序，《马尔谷福音》9:44、9:46及《路加福音》17:36在所用思高底本中不单列正文；这里沿用思高本，不从和合本填入。译名表与来源链接一并公开，便于继续校订；结构检查不代替逐字的学术校勘。
